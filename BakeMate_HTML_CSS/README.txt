BAKEMATE — GÓI HTML + CSS

Tệp trong gói:
- index.html: trang chủ mẫu
- products.html: danh sách 8 sản phẩm
- product-detail.html: trang chi tiết sản phẩm mẫu
- about.html: trang giới thiệu BakeMate đã tạo trước đó
- css/style.css: stylesheet chung cho bốn trang
- images/: thư mục dành cho ảnh nội bộ của nhóm (hiện để trống)

Cách chạy:
1. Giải nén ZIP.
2. Mở thư mục bằng VS Code.
3. Mở index.html bằng trình duyệt hoặc dùng Live Server.
4. Dùng menu để chuyển giữa Trang chủ, Sản phẩm và Về BakeMate.

Lưu ý:
- Hình ảnh hiện lấy từ Unsplash nên cần kết nối Internet.
- Tên/giá sản phẩm và nội dung chi tiết là dữ liệu minh họa; thay bằng dữ liệu nhóm đã xác nhận.
- Các liên kết xem chi tiết hiện cùng trỏ tới product-detail.html mẫu.
- Không có JavaScript, framework CSS, backend hoặc thanh toán thật.
- Đây là gói giao diện mẫu dựa trên trang giới thiệu BakeMate đã tạo trước đó, không phải bản ghép từ các tệp HTML riêng mà bạn chưa tải lên cuộc trò chuyện.
